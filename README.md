# MX Flow

> **Build your own media workflow.**

### **We believe great media software should work together, not compete with each other.**

MX Flow is an open-source media workflow platform.

Instead of replacing existing applications, MX Flow connects them into one intelligent ecosystem.

We connect great software instead of rebuilding it.

---

## Why MX Flow?

Today's media experience is fragmented.

Searching, downloading, organizing, subtitles, AI, media libraries, and playback are often handled by different applications that rarely work together.

MX Flow aims to unify these workflows through an open and extensible platform.

Users should be free to choose the best tools for every task without sacrificing a seamless experience.

---

## Our Philosophy

We don't believe there is one perfect media application.

Instead, we believe every great application has its own strengths.

MX Flow exists to connect them.

Rather than replacing Kodi, Jellyfin, Emby, Plex, MPV, VLC or future applications, MX Flow provides a common workflow that allows them to work together.
