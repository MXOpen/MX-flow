# MX Flow Vision

## Vision

**Build your own media workflow.**

MX Flow is an open and composable media workflow platform.

We believe great media software should work together, not compete with each other.

MX Flow doesn't replace great software. It connects it.

---

## Core Principles

* Open
* Composable
* Modular
* Extensible
* Community-driven

---

## Mission

Enable everyone to build their own media workflow without being locked into a single ecosystem.
